## Security Engineering Tools
----
My collection of tools for all the parts of Cybersecurity, mostly focused on Digital Forensics, Redteaming and Cryptography.  
----
Current collection includes:  

# Networking Tools:  
- cuckoo, a netcat clone written in Python  
- kiwi, a HTTP header scanner written in Go  
- mantis, a TCP port scanner  

# Digital Forensics Tools:
- pollen, an EXIF Data Bulk Extractor & Geolocation Mapper written in Ruby  

# Cryptography Tools:
- corvid, a hasher identifier written in Go  
- crow, a cypher identifier/cracker written in Go  
- hashdog, a hashcat clone written in Python
